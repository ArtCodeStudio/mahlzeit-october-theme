{# Client-side behaviour for the JumpLink.Vouchers purchase form. Rendered once from the barba body partial (OUTSIDE #barba-wrapper), so it runs on a full page load and survives barba's async page swaps. The handlers are delegated on `document` — like Winter's data-request — because barba replaces the page content via innerHTML and never executes scripts inside it, so a script living in the form partial would not run after an in-site navigation (that was the "clicking 50 € does nothing" bug). #}
